# SuperHome（超级影视桌面）的 App 名称与分组预设
#
# 一行一条，# 开头是注释，空行忽略；字段之间用空格或 Tab 分开。
# 文件请存成 UTF-8；Windows 记事本默认的 GBK 也能读（程序自己判断）。
#
# 放哪里（三处都读，优先级从高到低）：
#   1. 你在 App 里 / 手机页给单个 App 改的名字            —— 最优先
#   2. 电视上的这个文件：/sdcard/tv/supeaerialappname.txt  —— 你自己放的，优先于云端
#   3. 云端下载的文件（地址见下文的 url，缺省 aerial.qust.me）
#   4. 打包进 APK 的这一份                                —— 没网也有预设名
#
# 语法：
#   name   包名   显示名（可以带空格）
#   group  组名（不能带空格）  包1,包2,包3
#   url    https://你的地址/supeaerialappname.txt    （只有本地文件里的 url 有效）

name com.hgtv.star            红果短剧TV
name com.ktcp.video           云视听极光
name com.gitvdemo.video       银河奇异果
name com.cibn.tv              CIBN 酷喵
name com.hunantv.license      芒果TV
name com.xiaodianshi.tv.yst   云视听小电视

# 分组示例：把这几行开头的 # 去掉，第一次开机时这几个 App 就会被收进「影视」文件夹。
# 已摆放过的 App 不会被移动：程序只处理它第一次见到的 App。
# group 影视 com.hgtv.star,com.ktcp.video,com.gitvdemo.video,com.cibn.tv,com.hunantv.license

# 「系统」文件夹不用写在这里：ROM 预装的 App（FLAG_SYSTEM）由程序自己收进去。
